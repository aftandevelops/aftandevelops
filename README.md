## ⚡ Featured Projects

- **[SheetParse](https://sheetparse.com)** — 100% in-browser PDF bank statement → Excel/CSV converter. Local-first parsing, on-device OCR, password-protected PDFs, and a column-alignment studio — zero uploads. (*Astro, React, Web Workers, pdf.js, Tesseract.js, SheetJS*)
- **[MyJSONPal](https://myjsonpal.com)** — Local-first JSON studio &amp; AST auto-repair engine with type inference and one-click exports. (*Astro, React, Web Workers, Monaco Editor, Tailwind CSS*)
- **[Aphronix Labs](https://aphronixlabs.com)** — Independent software studio where the products above are designed, built, and shipped. ([Founder page](https://aphronixlabs.com/founder))
